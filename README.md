# SlimeMate · 史莱姆伴侣

适用于 Minecraft Java 版 1.21.1 和 NeoForge 21.1.265 或更新的 21.1.x 版本。运行和构建均使用 Java 21。

## 玩法

- 用 6 个黏液球合成斐济贝，再用斐济贝和 5 个任意颜色的羊毛升级成 3D 人偶。
- 按住右键 5 秒装填。松开后再次右键发射。地面上的粘液可用普通纸擦掉。
- 持有人偶时按 **K** 换肤。支持局内玩家、按正版用户名搜索和导入 64×64 PNG。潜行右键地面顶面可摆放人偶。
- 物品提示显示最近使用者和累计使用次数。联机时客户端和服务端都需安装同一版本。

## 构建

Windows 运行 `gradlew.bat build`，Linux 或 macOS 运行 `./gradlew build`。生成的 JAR 位于 `build/libs/`。
